# Glossary — ch15-access-and-features.md

- **feature_catalog** — Feature catalog entry: one row per feature the Platform offers.
- **org_feature_flags** — Organization feature state: entitled and enabled switches per feature.
- **location_feature_overrides** — Location override: switches an organization-active feature off at one location.
- **employment_roles** — Role: a system or custom role with its permissions JSON.
- **nav_layouts** — Sidebar layout: a clinic's arrangement of navigation keys.
- **Active feature** — A feature whose catalog entry is active, which is entitled (trial not expired) and enabled.
- **Trial entitlement** — An entitlement with `entitled_until` set; it ends at that moment.
- **Clinic default layout** — A `nav_layouts` row with `role_id` null.
