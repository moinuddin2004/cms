# Glossary — ch23-inventory

- **Inventory category** — an organization's grouping of stock items (`inventory_categories`).
- **Inventory item** — one stocked item at one location with its current stock (`inventory_items`).
- **Stock movement** — one signed change to an item's stock, with before/after snapshots (`stock_movements`).
- **Supplier** — a vendor of stock (`suppliers`).
- **Purchase order** — an order to one supplier for one location (`purchase_orders`).
- **Purchase-order item** — one item line on a purchase order (`purchase_order_items`).
- **Consumption template** — a standard kit of materials for a procedure (`consumption_templates`).
- **Consumption template item** — one item and default quantity in a kit (`consumption_template_items`).
- **Patient consumption** — materials used on one patient (`patient_consumptions`).
- **Patient consumption item** — one item used, with price snapshot (`patient_consumption_items`).
- **Legacy inventory table** — an unregistered single-table item list, superseded (`inventory`).
